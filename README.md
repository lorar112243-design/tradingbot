# tradingbot

Папка проекта уже создана, и я добавляю рабочий стартовый бот для торговли на криптовалютных рынках.

## Что это

Это простой торговый бот-песочница (paper trading), который:
- получает исторические свечи с Binance API;
- рассчитывает простые скользящие средние (SMA);
- принимает решения по сигналам тренда;
- позволяет запустить симуляцию без реальных денег и API-ключей.

## Структура проекта

- `bot.py` — основной бот и стратегия;
- `requirements.txt` — зависимости;
- `.gitignore` — стандартные исключения.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python bot.py --symbol BTCUSDT --interval 1h --limit 200 --capital 1000
```

## Что умеет бот

- подключаться к публичному Binance API;
- получать последние данные по выбранной валютной паре;
- вычислять короткую и длинную SMA;
- генерировать сигналы BUY / SELL / HOLD;
- проводить простой симуляционный backtest.

## Важно

Этот бот предназначен для обучения и тестирования стратегии, а не для автоматической торговли на реальном счёте без дополнительной настройки и проверки рисков.
